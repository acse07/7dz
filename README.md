# ДЗ7 — доска объявлений

Простой фронтенд на React и TypeScript. Минимум CSS, без Babel и дополнительных библиотек интерфейса.

## Запуск

Нужен Node.js 24.

```sh
npm ci
npm run dev
```

Проверка типов и сборка: `npm run build`. Просмотр сборки: `npm run preview`.

## Как читать код

- `src/main.tsx` — подключение React и CSS.
- `src/App.tsx` — вся логика и разметка одной страницы.
- `src/style.css` — простое оформление.
- `vite.config.ts` — относительные пути, чтобы сайт работал в папке GitHub Pages.
- `.github/workflows/deploy.yml` — установка зависимостей, проверка TypeScript, сборка и деплой из `main`.

В `App.tsx` тип `Ad` описывает объявление, а `AdsResponse` — ответ со списком. `useState` хранит объявления, номер страницы и состояние запросов. `useEffect` вызывает GET при открытии; при уходе со страницы запрос отменяется.

`loadAds` запрашивает `GET https://inai-col1.fishrungames.com/ads` с параметрами `page` и `limit`. `HIDDEN_IDS` содержит номера старых объявлений, скрытых на сайте: из прежнего списка оставлены «Пять айфонов», «ноут» и «ВЕЛИК». Записи в общем API не удаляются, новые публикации отображаются. Список выводится через `map`, для элементов используется `key={ad.id}`. Если видимых записей больше 12, они делятся на страницы через `slice`. Относительные пути изображений дополняются адресом сервера.

`submitAd` отменяет перезагрузку формы через `preventDefault`, проверяет поля и отправляет `FormData` через POST на тот же адрес. Поля: `title`, `description`, `price`, `image`. Фото обязательно: API возвращает 422, если файл не передан. Заголовок `Content-Type` браузер задаёт самостоятельно. При успехе форма очищается и список обновляется. При ошибке введённые данные сохраняются; ошибки сети, сервера и слишком большого фото показываются отдельно.

Vite обрабатывает TSX без Babel. Команда `tsc --noEmit` отдельно проверяет типы перед сборкой.

## GitHub Pages

В репозитории: Settings → Pages → Source → **GitHub Actions**. При push в `main` workflow собирает `dist` и публикует артефакт Pages. Ветка `gh-pages` не используется.
